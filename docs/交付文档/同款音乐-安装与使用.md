# 悦音音乐：安装与使用

版本：0.3.2。安卓独立包标识：`app.videomusic.player`。

这是依据用户提供的视频重新实现的独立界面，基于 MIT 开源项目 [Mconnect](https://github.com/Hjdd14/Mconnect-Music_connect) 的账号、音频、存储基础扩展。源码保留上游许可和版权。没有取得视频里原应用的源码，也不会复制录屏者的账号或收藏数据。

## 安装包选择

- `arm64-v8a`：绝大多数近年安卓手机选这个。
- `armeabi-v7a`：较旧的 32 位安卓设备。
- `x86_64`：安卓模拟器及部分 x86 设备。

在安卓设备打开相应 APK，并按系统提示允许该来源安装。应用和原 Mconnect 包名不同，可同时安装。后续更新应沿用本次稳定签名；签名材料保留在本任务私有目录，不包含在源码压缩包内。


## 0.3.2 覆盖升级

新包安装后桌面名称为“悦音音乐”，使用蓝紫色唱片音符图标。使用相同架构的新 APK 直接覆盖旧版，保留已保存的音源与设置。QQ 旧会话若提示失效，请重新扫码后同步“我喜欢”。

本轮新增 QQ 授权和收藏协议、音源编码与网络回调兼容。包校验和自动化结果见“安卓安装包/校验信息-0.3.2.md”；本轮未连接设备，真实账号与所有第三方音源仍需手机实测。历史截图和此前模拟器记录不是 0.3.2 的设备验证结果。

## 使用

1. 在“我的”分别进入 QQ 音乐、网易云，使用对应手机客户端扫码并确认。QQ 二维码获取失败会显示通用说明和“重试”；未扫码时显示等待扫码。登录信息保存在设备安全存储；无需把密码交给开发者。
2. 登录后到对应平台页查看“我喜欢”。同步期间显示已经载入的歌曲及真实总数；遇到错误保留已同步部分，并标明未完整同步。
3. 在“搜索”输入歌曲或歌手并提交，使用本地、QQ 音乐、网易云胶囊切换来源。列表可继续分页，结果数来自当次平台响应。
4. 点歌曲打开播放页。底部迷你播放器、全屏播放器和队列使用同一个播放状态；点击封面或歌词按钮切换歌词视图，点击歌词行定位播放。
5. “我的”可选择两平台播放与下载音质、浅色/深色/系统主题、缓存上限和存储位置。音质选项代表请求，实际音源信息单独显示；平台拒绝时给出失败提示。
6. 歌曲菜单可下载；下载管理显示进度和具体错误。可播放的已完成本地下载可直接打开。Android 系统文件夹中的 SAF 文档若不能直接播放，会明确提示，不冒充离线播放成功。
7. 本地音乐使用系统文件夹选择器导入。缓存上限默认 10240 MB，是上限，不会预先占用 10 GB；离线模式只使用已经存在的可播放缓存文件。

## 自定义音源链接导入

进入“我的 → 自定义音源”，粘贴具体 `.js` 的 HTTPS 下载链接，点击“从链接导入”。也支持 GitHub 的具体文件页面链接；仓库首页不能作为音源。导入完成后核对名称和平台，打开“启用自定义音源”，再点“保存”。下载使用另一个开关，默认关闭。

你提供的仓库中 Huibq 的下载链接示例（内容可能由作者更新）：

```text
https://raw.githubusercontent.com/pdone/lx-music-source/main/huibq/latest.js
```

本轮在正式 APK 实测导入的是同一仓库固定提交的以下地址；它与 GitHub 原文件的 SHA-256 一致。若上面的 GitHub 地址在当前网络不可达，可粘贴这个已核对的版本：

```text
https://fastly.jsdelivr.net/gh/pdone/lx-music-source@000578ddca4a676012cf735abdc3489efdc67c74/huibq/latest.js
```

实际显示名称 `Huibq_lxmusic源`、版本 `v1.2.0`、QQ 音乐和网易云。已验证下载、初始化和保存管理；未验证该服务的真实歌曲解析与播放。

重新打开该页面可测试初始化、重新导入更新、禁用或删除。测试通过只代表脚本初始化成功；歌曲是否可播放取决于音源服务及其支持的歌曲和音质。官方成功时继续使用官方结果，明确不可用时才尝试已启用源；界面标记自定义来源和“规格未验证”。

0.3.1 修复了“浏览器能打开 GitHub Raw，软件却提示下载失败”：当具体 `raw.githubusercontent.com` 文件直连失败时，应用自动尝试同仓库、同分支和同路径的备用下载线路，保存的仍是你粘贴的原链接。用户提供的 `lx/latest.js` 已实际导入为“独家音源”版本 7：

```text
https://raw.githubusercontent.com/pdone/lx-music-source/main/lx/latest.js
```

洛雪脚本功能需要 Android 8.0 以上和支持隔离运行的 Android System WebView。目前支持最小 `lx` 事件与请求接口，不保证仓库全部脚本可用；依赖尚未实现的 crypto、zlib 等接口会报错。HTTPS 下载地址必须在设备当前网络可达，下载失败时检查具体链接和网络。源码与 APK 没有附带第三方音源脚本。

原 HTTP JSON 配置继续保留在页面底部的“HTTP 音源设置”，协议见《自定义音源-HTTP接入协议》。HTTP 与脚本音源互斥启用；原 HTTP 配置保留。

## 源码构建

入口：`lib/main_video.dart`。Flutter 固定 3.47.5，使用其自带 Dart；安卓构建使用 Java 17 和 Android SDK。任务内的 `scripts/build_video_apk.ps1` 接受 `FlutterSdk`、`AndroidSdk`、`Jdk`、`SigningProperties` 四个参数，并按架构生成 release 分包。已验证环境还包含 Android 平台 34、35、36，NDK 28.2.13676358 和 CMake 3.22.1。

干净源码不包含 `.dart_tool`、插件依赖清单和本机 `android/local.properties`。先在源码根目录运行固定 Flutter 的 `pub get`，使依赖解析及插件链接成功，再执行构建脚本。脚本使用 `--no-pub`，会用固定 SDK 的官方生成逻辑补齐 Android 插件注册器，但不能替代首次依赖解析。

Windows 必须支持插件所需的符号链接，通常通过系统“开发者模式”启用。若 `pub get` 提示 `Building with plugins requires symlink support`，先解决该环境提示，再重新执行至成功。不要把依赖准备失败或缺少插件注册器时生成的包当作可用产物。

以下为 PowerShell 示例，先进入解压后的源码根目录，再把四个路径替换为本机实际位置。示例的签名配置放在源码目录之外；工具缓存沿用构建脚本的“源码目录上两级 / work/toolchains”布局，以便依赖准备与构建读取同一个 Pub 缓存。

```powershell
$videoFlutterSdk = 'C:/AndroidTools/flutter-3.47.5'
$videoAndroidSdk = 'C:/AndroidTools/android-sdk'
$videoJdk = 'C:/AndroidTools/jdk-17'
$videoSigningProperties = 'C:/Private/video-music-signing.properties'
$videoProjectRoot = (Get-Location).Path
$videoTaskRoot = Split-Path -Parent (Split-Path -Parent $videoProjectRoot)
$env:PUB_CACHE = Join-Path $videoTaskRoot 'work/toolchains/pub-cache'
$env:PUB_HOSTED_URL = 'https://pub.flutter-io.cn'
$env:FLUTTER_STORAGE_BASE_URL = 'https://storage.flutter-io.cn'
& (Join-Path $videoFlutterSdk 'bin/flutter.bat') pub get
if ($LASTEXITCODE -ne 0) { throw '请先完成依赖解析与 Windows 插件链接准备' }
& './scripts/build_video_apk.ps1' `
    -FlutterSdk $videoFlutterSdk `
    -AndroidSdk $videoAndroidSdk `
    -Jdk $videoJdk `
    -SigningProperties $videoSigningProperties
```

`SigningProperties` 指向 Java properties 格式的私有文件，必须提供以下四个字段；`storeFile` 使用 PKCS12 密钥库的绝对路径，路径建议用正斜杠。下面全部是占位值，不能直接用于签名。

```properties
storeFile=C:/Private/video-music-release.p12
storePassword=<keystore-password>
keyAlias=<key-alias>
keyPassword=<key-password>
```

覆盖升级必须沿用本次发布的密钥库和别名；另建密钥只适合新安装，不能覆盖当前已安装版本。签名配置、密钥库、密码和账号凭据不进入源码或源码压缩包。构建产物在 `build/app/outputs/flutter-apk/`，包含 `app-arm64-v8a-release.apk`、`app-armeabi-v7a-release.apk`、`app-x86_64-release.apk`。

默认 `lib/main.dart` 仍为原应用入口；未启用 `VIDEO_MUSIC_BUILD=1` 时，原包名、应用名及签名方式保持原行为。
