# 悦音音乐源码发布说明

本源码对应悦音音乐 Android 0.3.3，发布整理日期为 2026-11-06。

## 来源与文件范围

源码基于 Mconnect 提交 `9df0c0feeb148d65cebe51fea5fe8d4387e16dcc` 修改与扩展。根 LICENSE 保留上游版权与 MIT 许可；第三方许可见[第三方组件说明](洛雪运行时第三方组件说明.md)。

本仓库使用整理后的完整源码快照建立独立提交历史。保留产品源码、工程配置、依赖锁定、正式回归测试、构建脚本和中文文档。

公开快照排除了 19 张历史交付截图、7 个 Windows 自动生成的插件链接占位文件，未收录本机 Git 历史、构建缓存、签名私钥、登录数据、音乐文件或第三方音源脚本。历史文档中的个人用户目录已替换为环境变量示意。截图原本对应旧版本，不能作为 0.3.3 的设备验收证明。

## 验证范围

发布整理核对所有纳入文件，按文件哈希检查产品源码、工程配置、正式测试及许可与原工作副本一致。检查私钥和常见凭据格式、个人目录，以及 README 和构建说明中的链接。检查不代表对任意秘密格式的绝对保证。

本次公开整理没有新增应用功能，也没有重新构建 APK。0.3.3 已有主机验收及仍待实测的设备场景见[验收记录](悦音音乐033验收记录.md)，不能将历史结果视为本次重测。

## 构建与维护

悦音音乐使用 `lib/main_video.dart` 和 `VIDEO_MUSIC_BUILD=1`，签名配置由构建者在仓库外准备，详见[开发与构建](悦音音乐开发与构建.md)。

仓库保留上游 CI 的检查与原默认入口构建。Actions 中名为 `mconnect-release-apks` 的构建产物属于原入口，不是悦音音乐签名发行包。悦音音乐的独立签名发布流程尚未配置。

APK 发布与源码上传分开进行；当前说明不表示已有 GitHub Release 附件。
