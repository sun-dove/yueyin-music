# 悦音音乐 0.3.3 使用说明

在原应用上覆盖安装同一架构的 0.3.3 APK，保留账号和音源设置。多数安卓手机使用 arm64-v8a；armeabi-v7a 用于旧款 32 位设备，x86_64 用于对应架构的电脑安卓模拟器。

## 多音源设置

1. 打开“我的 → 自定义音源”，进入“多音源管理”。旧版单个音源会自动出现。
2. 粘贴具体 HTTPS 脚本链接，点“从链接导入”。同一链接更新原条目，不覆盖其他音源。
3. 启用要使用的音源，设置首选；其余音源可上移、下移。新导入源默认关闭。
4. 点“使用推荐设置”，开启音源优先、失败自动切换和最高可用音质，再点“保存设置”。设置只在保存后生效。
5. 播放页上方显示当前尝试来源；“查看详情”列出失败、不参与和未试项。等待达到预算上限时可点“继续尝试剩余音源”。

最高可用按 Hi-Res、无损、HQ、标准顺序尝试，在同档位先试各个符合条件的源，不会因为首选源只有标准就忽略后面的无损源。固定音质可在音质设置中选择。下载音质独立，不随最高播放模式改变；下载仅使用允许下载的源。

关闭所有自定义源仍可尝试 QQ/网易云官方播放。选择 HTTP 音源并启用后，洛雪条目会保留但停用，切回洛雪时重新启用并保存。

## 如何理解音源结果

- 导入成功说明脚本已下载并完成初始化，歌曲播放仍待验证。
- “未声明支持”表示源没有声明当前平台或档位，不会调用该不适用组合。
- 加载失败会继续尝试其他候选；播放中断后尝试保留进度。无法定位时明确提示从头播放。
- “请求无损”表示请求档位；没有可靠媒体信息时显示“音质待验证”。不能只凭源名称、URL 或接口声明证明实际音质。
- 源脚本缺接口、服务超时、曲目无资源、登录失效是不同问题。导入成功不保证 VIP 歌曲一定能播。

本轮没有连接安卓设备。仓库全部 16 个脚本均已在电脑下载并记录哈希，但新版 Android 初始化、指定曲目取流、完整音频播放和各音质均未实测。历史通过的 8 个源也不能据此标为新版全部可播放。

若仍失败，可提供具体音源链接和页面错误文字；不需要提供账号 Cookie 或访问令牌。对于《窝囊废》，目前还缺歌手/具体版本和官方 App 播放对照，不能断定唯一原因。
