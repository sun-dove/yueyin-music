# 悦音音乐开发与构建

本文针对悦音音乐独立入口 `lib/main_video.dart`。当前版本为 0.3.3，Android 构建号为 6，包名为 `app.videomusic.player`。

## 环境

- 使用仓库固定的 Flutter 3.47.5 / Dart 3.13.4；版本依据见根目录 pubspec.yaml 和 .github/workflows/ci.yml。
- 安装 JDK 17、Android SDK，并准备可用的 Android 设备或模拟器。
- 完整回归需要 Node.js，确保命令 `node` 在 PATH 中可用。LX 算法对照用例使用它运行固定的测试代码。
- 下文命令使用 Windows PowerShell，并从仓库根目录执行。

以下均为示例路径，请替换成自己机器上的目录。SDK 和缓存可放在 D 盘；签名目录应在仓库外。

```powershell
$flutterSdk = 'D:/MusicDev/flutter'
$env:JAVA_HOME = 'D:/MusicDev/jdk-17'
$env:ANDROID_HOME = 'D:/MusicDev/android-sdk'
$env:ANDROID_SDK_ROOT = $env:ANDROID_HOME
$env:PUB_CACHE = 'D:/MusicDev/pub-cache'
$env:GRADLE_USER_HOME = 'D:/MusicDev/gradle-home'
$env:PATH = (Join-Path $env:JAVA_HOME 'bin') + ';' + (Join-Path $flutterSdk 'bin') + ';' + $env:PATH

flutter pub get
```

## 配置自己的签名

开启 `VIDEO_MUSIC_BUILD=1` 后，Gradle 会读取 `VIDEO_MUSIC_SIGNING_PROPERTIES` 指定的配置。该要求在配置阶段生效，运行独立入口或打包前均需准备。

为自己的发行版创建 PKCS12 密钥，下面的命令会交互询问口令：

```powershell
New-Item -ItemType Directory -Path 'D:/MusicDev/signing' -Force | Out-Null
keytool -genkeypair -v -keystore 'D:/MusicDev/signing/yueyin.p12' -storetype PKCS12 -alias yueyin -keyalg RSA -keysize 2048 -validity 10000
```

在仓库外创建 `D:/MusicDev/signing/key.properties`，内容如下。示例没有真实口令，请自行填写：

```properties
storeFile=D:/MusicDev/signing/yueyin.p12
storePassword=填写自己设置的口令
keyAlias=yueyin
keyPassword=填写自己设置的口令
```

把配置交给当前 PowerShell 会话：

```powershell
$env:VIDEO_MUSIC_BUILD = '1'
$env:VIDEO_MUSIC_SIGNING_PROPERTIES = 'D:/MusicDev/signing/key.properties'
```

签名私钥和口令不随源码发布。使用自己的新签名构建的 APK，不能直接覆盖安装原签名发行的 APK；维护既有安装用户时，应使用原发行签名。

## 生成插件注册器并构建

项目保留了独立的 Android 插件注册器生成步骤，首次拉取依赖或插件发生变化后执行：

```powershell
$dart = Join-Path $flutterSdk 'bin/cache/dart-sdk/bin/dart.exe'
$toolPackages = Join-Path $flutterSdk 'packages/flutter_tools/.dart_tool/package_config.json'
& $dart "--packages=$toolPackages" 'scripts/generate_android_plugins.dart' (Get-Location).Path
if ($LASTEXITCODE -ne 0) { throw 'Android 插件注册器生成失败' }
```

调试悦音音乐：

```powershell
flutter run --target lib/main_video.dart
```

发布构建按架构分包：

```powershell
flutter build apk --release --split-per-abi --no-pub --target lib/main_video.dart
```

| 文件 | 用途 |
| --- | --- |
| build/app/outputs/flutter-apk/app-arm64-v8a-release.apk | 大多数安卓手机 |
| build/app/outputs/flutter-apk/app-armeabi-v7a-release.apk | 支持的旧款 32 位设备 |
| build/app/outputs/flutter-apk/app-x86_64-release.apk | x86_64 安卓模拟器或设备 |

`VIDEO_MUSIC_BUILD` 控制 Android 包名、名称、版本和签名；`--target lib/main_video.dart` 控制 Dart 入口。两者应同时设置。pubspec.yaml 中的 1.5.0+16 属于原 Mconnect 默认入口，不能作为悦音音乐版本号。

已有维护脚本[build_video_apk.ps1](../../scripts/build_video_apk.ps1)封装了插件生成与打包步骤，但其默认工具链、缓存和签名位置依赖现有工作区布局。独立克隆时可按本文显式配置路径。
