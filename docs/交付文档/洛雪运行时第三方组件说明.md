组件及完整许可包含在 Flutter assets 和源码包中，并加入独立入口的 LicenseRegistry。应用运行时不从 CDN 下载这些组件，不暴露 Node、文件系统或平台账号凭据。安全随机字节来自 Dart Random.secure，每个隔离运行实例提供 64 KiB 随机池；缓冲区和解压输出限制为 512 KiB。

正式回归用 Node 作为受信任计算代码的对照运行器，验证 27 项断言：MD5、二进制与 UTF-8、ArrayBuffer 视图、AES 各密钥长度及 CBC/ECB/CTR/CFB/OFB、RSA 无填充约定、随机长度、压缩往返与超限、无宿主系统接口。Node 不是第三方音源的执行环境。全部第三方音源仍只允许在 Android 专用隔离沙箱运行。

这是洛雪常用接口的兼容实现，不等于完整 Node Buffer/crypto 或浏览器 DOM。没有实现的接口仍明确失败；平台限制、源服务失效和具体歌曲能否取得音频必须另验。
